# Kosmik Circles V1.6 — Image persistence fix

Fixed the Admin image workflow so uploaded images are persisted to `backend/uploads/`, returned by the API, rendered immediately in the Admin, and displayed by the public pages.

## Fixed points
- Admin accepts same-origin/local image paths such as `/backend/uploads/...`.
- Save uses the normalized server response so newly uploaded images appear immediately.
- Existing persisted image URLs are preserved when saving content again.
- Public pages already accept same-origin image paths and now receive the stored URLs consistently.

No visual redesign was made.
