# Kosmik Circles — Gallery Archive V1.14

The public Gallery is now an event/night archive. Visitors see folders for each night, open a folder, view its photos/videos and download each file.

## Admin workflow
1. Add a night folder.
2. Set title, date, location, venue and description.
3. Upload a cover image.
4. Upload multiple photos/videos (max 1 GB per file).
5. Save the folder.
6. Delete individual media or the whole folder when needed.

## Public workflow
Gallery → folder → media → Download.
