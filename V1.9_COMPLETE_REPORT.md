# KOSMIK CIRCLES V1.9 — Complete pre-production pass

## Scope

This release continues from V1.8 and focuses on operational content management, image-slot reliability, responsive behavior, performance hygiene, and production hardening. The existing visual identity has not been redesigned.

## Content / text slots

The CMS now persists the major public-facing text slots server-side, including:

- Home hero, signal strip, orbit labels, hero index and intro block
- Page headings for Shop, Gallery, Live, Contact, Us and Cart
- Navigation labels and shop count
- Shop add-to-cart label
- Gallery empty-slot label
- Live table headers
- Contact form labels and submit label
- Cart form labels, quantity/total labels, empty/sending/remove text
- Footer tagline and page-specific footer CTA labels
- Contact section/service/form texts
- Us statement, studio label, sound section and values section

Text changes are saved through the Admin API into SQLite and reloaded from the server.

## Image slots

15 image slots were exercised through upload → save → reload → replace → old-file cleanup:

- 1 Home hero image
- 1 Us studio image
- 3 Us sound images
- 1 Live background image
- 5 Gallery images
- 4 Shop product images

The old uploaded asset is removed only when it is no longer referenced by another CMS slot.

## Important image fixes

- Upload uses a dedicated binary endpoint instead of sending large Base64 payloads through the CMS save request.
- Local uploaded paths are normalized before persistence.
- Orphaned managed uploads are pruned when content is saved.
- The second Us sound slot keeps its bundled local WebP default.
- Live background is now a CMS-controlled image slot while retaining the existing visual treatment.

## Data integrity fixes

- Product records are synchronized by stable product name/ID rather than delete-and-recreate, preserving product IDs referenced by historic orders.
- Default content is merged into legacy databases without replacing existing values.
- A one-time legacy migration restores the original Live archive when upgrading the old V1.8 schema.

## Responsive / performance changes

- Added tablet breakpoint at 900px and retained mobile breakpoint at 700px.
- Fixed the Live event row mobile grid so the ticket/action control cannot overlap the event detail column.
- Added global image max-width safety and min-width protections for grid/flex children.
- Added long-email wrapping in Contact.
- Removed duplicate Google Fonts CSS @import and keeps explicit font preconnect/link loading in pages, including Cart and 404.
- Matrix rendering is capped on narrow screens to reduce unnecessary CPU work while preserving the visual effect.
- Non-hero images use lazy loading and async decoding.

## Security / production hygiene

- Added Content-Security-Policy and HSTS when the request is served behind HTTPS with X-Forwarded-Proto.
- Sensitive backend source, environment file and SQLite paths remain inaccessible as static resources.
- Image upload validates content type and file signatures and enforces a 5 MB limit.
- Manual Admin changes to PAID are blocked; payment confirmation remains provider/webhook controlled.
- `http://` remote image URLs are no longer accepted by the server-side content normalizer; local assets and HTTPS assets are accepted.

## What is intentionally not final yet
