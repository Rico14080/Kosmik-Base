# Kosmik Circles V1.7

## Fix principale
- Risolto il problema `Failed to fetch` durante il salvataggio delle immagini dall'Admin.
- Le immagini vengono ora inviate al backend come file binario tramite `POST /api/admin/upload`, invece di essere incorporate come Base64 nel payload CMS.
- Il salvataggio CMS contiene solo l'URL dell'immagine, evitando payload troppo grandi.
- Aggiunta validazione del tipo immagine tramite Content-Type e firma del file (magic bytes).
- `/api/health` espone la versione backend `1.7` per identificare rapidamente quale server è in esecuzione.
- L'Admin mostra un messaggio più utile quando l'API non è raggiungibile.
- Gestione delle richieste JSON troppo grandi migliorata evitando il desincronizzamento della connessione.

## Grafica
Nessuna modifica intenzionale a layout, palette, font, Matrix o stile generale.
