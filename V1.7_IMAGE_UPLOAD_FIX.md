# Kosmik Circles V1.7 — Image Upload / API Fix

## Fixed
- Admin images are uploaded directly as binary files to `/api/admin/upload` instead of embedding base64 data inside the CMS save payload.
- Uploads are limited to 5 MB and validated by Content-Type and magic bytes.
- CMS save payloads stay small, avoiding oversized-request connection failures and browser `Failed to fetch` errors.
- `/api/health` now exposes backend version `1.7` for quick verification of the running server.
- Admin API errors now explain which API URL is being used when a connection cannot be established.

## Usage
Open the admin from the same server that runs the backend, e.g. `http://127.0.0.1:8080/admin.html`.
