# Kosmik Circles V1.12 — Image slot / preview fix

- Home hero now uses the selected image as a container background only after the browser successfully loads it; the orbital CSS artwork is disabled while that image is valid.
- Uploaded files under `/backend/uploads/` are served explicitly by the Python backend.
- Admin previews are available for Home, Us Studio, Live Background, Gallery, Us Sound and Shop product slots.
- Selecting a local file shows an immediate preview before the upload finishes.
- Shop image slots now show a preview in Admin instead of only a Replace button.
- Existing public visual design remains unchanged when slots are empty.
