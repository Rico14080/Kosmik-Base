Cookie & Local Storage Information

Kosmik Circles does not currently use advertising cookies, analytics cookies, behavioural profiling pixels or marketing trackers. The private administration area uses a strictly necessary session cookie named for the Kosmik administrative session. It is used only to authenticate the administrator and protect administrative actions. It is not used for advertising or profiling. The website code may use browser local storage for technical interface state, including cart-related state. The direct online store is currently disabled and the Shop functions as a visual catalogue, so no advertising or profiling purpose is attached to this storage. Google Fonts is loaded from Google infrastructure. This is an external network request rather than a Kosmik advertising cookie and may disclose technical connection information to Google. Because the current public configuration does not use non-essential tracking technologies that require prior consent, no marketing-cookie consent banner is presently enabled. If analytics, advertising pixels, embedded third-party media or other non-essential tracking technologies are added later, this information and the consent mechanism must be reviewed before activation.
