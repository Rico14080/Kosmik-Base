# Kosmik Circles V1.12 — Image slot / Home / Admin preview fixes

## Public pages
- Home hero custom image is applied as a background only after the browser confirms the image loads.
- When the Home hero image is active, the original orbit/planet CSS artwork is completely disabled.
- Uploaded files under `/backend/uploads/` are explicitly served by the backend with immutable caching.
- Managed Shop images are marked so a failed load cannot leave the placeholder layer active.

## Admin
- Home, Us Studio, Live Background, Gallery, Us Sound and Shop product slots now have visible previews.
- Selecting a local image immediately shows a local preview before upload completes.
- Shop product slots now show the current image instead of only a Replace button.
- Gallery and Sound slots show current images consistently.

## Design
- Public-site visual design and empty-slot artwork are preserved.
