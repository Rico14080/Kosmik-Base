# V1.11 — complete image replacement behavior

## Fixed
- Home hero visual: when a custom image exists, the decorative orbital CSS illustration is hidden, so the custom image is the only visual slot content.
- Shop: when a product image exists, CSS-generated product art is hidden and the uploaded image is shown fully opaque without blend mode.
- Gallery: custom images no longer retain the placeholder layer.
- Us / Studio: managed image element replaces the CSS background placeholder.
- Empty image slots keep their original decorative placeholders, so the design is unchanged when no image is selected.

No payment/server/domain/email configuration was changed.
