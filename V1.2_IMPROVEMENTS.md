# Kosmik Circles V1.2 — Technical Improvements

## Scope
This release continues Phase 1 using the V1.1 Phase 1.2 project as the source. The visual design, layout, typography, palette and Matrix aesthetic are intentionally preserved.

## Completed
- Normalized page metadata and descriptions.
- Added strict referrer policy on public pages.
- Added preconnect hints for Google Fonts.
- Deferred `site.js` so HTML parsing is not blocked.
- Added skip-to-content and visible keyboard focus support.
- Added reduced-motion handling for the Matrix/ticker.
- Added safer URL handling (HTTPS/relative; controlled image data URLs for local admin previews).
- Added HTML escaping and safer dynamic image handling.
- Hardened cart normalization and quantity bounds (1–99).
- Hardened price parsing for common EUR formats.
- Added contact-form length/email validation and a hidden honeypot field.
- Limited locally stored messages to the newest 100 entries.
- Added missing Instagram URL and ticket URL fields to the admin editor.
- Added a 5 MB image upload limit in the local admin editor.
- Replaced the known broken remote image in `us.html` with a packaged project image.
- Added `404.html`, `robots.txt`, `security.txt`, and `site.webmanifest`.
- Added technical comments/documentation without changing the visual identity.

## Intentionally not done yet
- Backend/database/authentication.
- Real payment processing.
- Server-side order/contact handling.
- Final legal text.
- Final canonical URLs/sitemap, because the production domain has not been confirmed.
- Hosting/DNS/HTTPS deployment.

These belong to the next production phase or require account/business information from the owner.
