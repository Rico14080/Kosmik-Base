# V1.8 — Image replacement cleanup

## Fix
When an image is replaced in Admin and the changes are saved, the previous local `/backend/uploads/` file is removed automatically if no other content entry still references it.

This applies to:
- Home hero image
- Us/studio image
- Shop product images
- Gallery images

Remote HTTPS images are never deleted.

## Expected flow
1. Upload the new image.
2. The Admin preview changes to the new image.
3. Click **Save changes**.
4. The old local image is removed when no longer referenced.
5. Reloading the site keeps only the new image.
